# Code Comments Checklist

- [ ] Comment explains why, not just what.
- [ ] Comment is close to the code it explains.
- [ ] Comment still matches current behavior.
- [ ] Public API docs describe caller-relevant behavior.
- [ ] TODO comments are actionable.
- [ ] Commented-out code is removed.
- [ ] Obvious comments are removed.
- [ ] Names are improved when they can replace comments.
