# React Checklist

- [ ] Component has one clear responsibility.
- [ ] Props are typed.
- [ ] State is minimal and close to where it is used.
- [ ] Derived values are not duplicated in state.
- [ ] Effects synchronize with external systems.
- [ ] Effects clean up subscriptions, timers, and event listeners.
- [ ] Lists use stable keys.
- [ ] Loading state is handled.
- [ ] Error state is handled.
- [ ] Empty state is handled.
- [ ] Interactive elements have accessible names.
- [ ] Markup uses semantic HTML where possible.
- [ ] Memoization is intentional.
- [ ] Tests or validation cover the changed behavior.
