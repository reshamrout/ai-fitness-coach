# TypeScript Checklist

- [ ] Exported APIs have clear types.
- [ ] Local inference is used where it improves readability.
- [ ] No new unbounded `any` is introduced.
- [ ] External data is validated or narrowed.
- [ ] Null and undefined are handled deliberately.
- [ ] Type assertions are narrow and justified.
- [ ] Discriminated unions model important variants.
- [ ] Generic types are necessary and readable.
- [ ] Runtime behavior matches declared types.
- [ ] Compiler and lint checks pass.
