# Clean Code Checklist

- [ ] Names match domain meaning.
- [ ] Functions do one coherent thing.
- [ ] Modules have clear ownership.
- [ ] Control flow favors readability.
- [ ] Duplication is reviewed for shared meaning.
- [ ] Side effects are visible.
- [ ] Dead code is removed.
- [ ] Comments explain context rather than obvious mechanics.
- [ ] Refactor scope stays tied to the task.
- [ ] Behavior is covered by tests or focused validation.
